# 多平台采集工作台 V2.2.2 更新说明

发布日期：2026-09-11

## 本次修复

- 完成 2.2 系列 GUI 优化：默认工作台统一使用新版 QML 界面，采集总览、任务中心、账号管理、线索中心、互动中心、设置与发布页面按独立业务页显示。
- 修复切换页面后内容互相堆叠、登录层覆盖关系错误和登录完成后业务页不刷新的问题；登录状态恢复后各业务页面可以正常进入。
- 优化任务中心表格列宽、进度和状态区域，避免 URL 详情、状态说明和操作按钮互相挤压或留下大块空白。
- 修复搜索阶段完成后，URL 队列没有被完整推进到详情页采集的问题。
- 修复人工验证后，旧版任务状态被监控轮询误判为可启动，导致任务显示运行但实际停在人工等待的问题。
- 修复单个详情页超时后仍占用平台采集通道的问题；超时页面会被取消，后续 URL 可以继续处理。
- 修复普通关键词监控任务在首轮完成后，下一轮到期不再重新搜索新增 URL 的问题。
- 修复抖音和其他平台楼中楼展开失败时的无限重试；达到重复无进展或点击上限后会停止展开，继续主评论采集。
- 修复旧任务在“搜索完成后人工验证”恢复时重新进入搜索阶段的问题，恢复后优先继续已有 URL。

## 监控说明

监控采集会在当前 URL 队列处理完成后进入下一轮搜索。人工验证或用户暂停中的任务不会被监控自动拉起，完成验证后请在任务中心点击“继续采集”。

## 数据与升级

本版本升级包只覆盖程序代码、资源、版本文件和监控脚本，不覆盖本地 `data`、`config`、`.venv`、账号绑定、浏览器登录态或历史采集数据。
