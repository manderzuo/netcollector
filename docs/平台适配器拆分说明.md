# 平台适配器拆分说明

项目已经预留独立平台代码边界。以后要把微博、B站、贴吧或其它平台单独摘出时，按下面结构复制即可：

    独立平台项目/
    ├─ platform_adapter.py       # 通用接口，可从 src/platforms/__init__.py 复制
    ├─ weibo_adapter.py           # 该平台的搜索、详情、评论解析
    ├─ export_mapping.py          # 该平台字段到统一导出字段的映射
    └─ requirements.txt           # 仅保留该平台需要的依赖

平台适配器只负责：

- 搜索并返回 vid/url/title/author；
- 打开详情页并提取平台内容；
- 返回标准评论字段：user_id、nickname、content、comment_time、region、extra；
- 处理平台自身的分页、冷却、验证码和登录态。

平台适配器不要直接依赖：

- gui.py
- SQLite 数据库
- 其它平台采集器
- 任务状态和账号分配逻辑

调度器只依赖通用 search / fetch_comments 接口。微博当前实现位于
src/weibo_chrome.py，使用普通 Chrome CDP；后续迁移到 BitBrowser 时，只需替换连接层，
保留页面解析函数。

新增平台时：

1. 新建 src/<platform>_adapter.py；
2. 实现通用接口；
3. 在 src/platforms/__init__.py 登记模块；
4. 在 GUI 平台映射中增加显示名；
5. 增加该平台的账号读取和导出字段映射；
6. 用独立测试账号回归搜索、详情、评论、分页和人工验证。
