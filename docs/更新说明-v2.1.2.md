# 多平台采集工作台 V2.1.2 更新说明

发布日期：2026-09-09

## 本次更新

- 修复长时间采集、评论较多时 GUI 卡顿的问题：日志和状态刷新信号合并处理，界面只消费最新状态，不再让 Qt 事件队列持续堆积。
- 限制常驻界面日志缓存为最近 1000 条，后台日志仍继续写入操作日志文件。
- 发布中心的生成内容支持删除，删除后会同步更新列表和总数，不影响已发布内容。
- 修复智能 API 配置校验与生成状态反馈，生成过程不会阻塞界面。
- 更新 macOS 交付副本和 Windows 运行目录中的同一套修复。

## 升级安全

- 更新器继续保留本地 `data`、`config`、`.venv`、账号绑定、浏览器登录态和已有采集数据。
- 完整发布包不包含本机数据库、账号、Cookie、API Key 或运行日志。

当前版本：`2.1.2`。

## 发送状态与慢浏览器修复

- 浏览器打开较慢时增加页面定位和发送结果等待，避免已发送内容被误判为失败。
- 重复点击已发送的评论或私信不会再次发送，已发送记录继续保留在“已回复”。
- 发送失败或状态刷新延迟时支持退回“待生成”；发送中的内容会显示发送中并禁止重复操作。
