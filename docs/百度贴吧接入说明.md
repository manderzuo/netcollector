# 百度贴吧接入说明

## 接入方式

百度贴吧使用已安装的 `tieba-claw` 官方 API 适配器，不依赖 BitBrowser 窗口，也不读取浏览器 Cookie。令牌只发送到 `https://tieba.baidu.com` 的官方接口。

在“诊断与设置”中填写 `TB_TOKEN` 并启用后，可以在新建采集任务中选择“百度贴吧”，添加贴吧账号（账号名仅作为本地任务归属标识，不需要窗口 ID），再选择关键词组或输入关键词。

## 已实现

- 帖子列表读取，支持最新帖子/热门帖子排序。
- 帖子楼层分页读取。
- 分页读取帖子楼层；当楼层存在楼中楼时，自动调用 `nestedFloor_claw` 补齐回复内容，并保留父楼层关系。
- 空内容自动过滤，评论 ID、昵称、用户 ID、内容、时间和来源地址写入现有采集入库链路。
- 平台下拉框、关键词组、线索中心、互动中心和健康诊断显示“百度贴吧”。
- `comment_thread`：在帖子下发表评论。
- `reply_to_post`：回复指定楼层；互动中心会把已审核草稿路由到贴吧官方 API。
- 填充/发送仍沿用互动中心的人工审核、确认和真实发送开关，预览阶段不会产生写操作。

## 当前边界

贴吧 skill 当前公开的帖子列表接口返回的是接口暴露的帖子列表，没有公开的关键词搜索参数或分页游标。适配器会读取列表后在本地按标题、摘要和作者进行关键词过滤；因此任务完成条件记录为“贴吧帖子列表接口已返回完毕”，不能等同于网页搜索结果已经穷尽。楼中楼接口按楼层返回的子回复数量按需调用，避免无意义请求。

真实接口调用前必须在设置中配置 `TB_TOKEN`。令牌不会写入操作日志、诊断摘要或测试输出。
