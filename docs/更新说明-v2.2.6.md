# 多平台采集工作台 V2.2.6 更新说明

发布日期：2026-09-16

## 本次更新

- 优化任务中心和采集总览的大批量任务状态刷新，减少界面拖动、切换页面和切换任务状态时的卡顿。
- 将评论采集后的意向分析统一改为批量提交；即使未启用 LLM，也按批次处理评论，避免逐条处理造成队列堆积。
- 优化评论补全、楼中楼和意向分析队列的收尾与退出流程，减少大量评论采集时后台阻塞和关闭不完整。
- 优化调度器状态汇总、日志写入和账号状态巡检，降低高频数据库查询与日志 I/O 对采集任务的影响。
- 优化监控采集运行记录的收尾，确保监控任务每轮运行都能及时更新状态。
- 延续 V2.2.5 的小红书、B 站、微博楼中楼回复定位修复，以及小红书风控降频处理。

## 升级说明

代码更新包会保留用户现有的 `data`、`config`、`.venv`、`.runtime` 和 `logs`；升级前建议关闭正在运行的采集任务，并保留现场日志。

如果升级后仍出现界面无响应，请同时保留 `data/gui_monitor.log`、`logs/update.log`、`logs/runtime_bootstrap.log` 和对应任务截图。
