## 本次发布内容

- 修复 Windows PowerShell 5.1 下 PySide6/pip 探测将 Python stderr 误判为致命异常的问题，使缺少运行依赖的客户端可以继续进入自动修复流程。
- 依赖修复优先使用发布包内的 wheel 缓存（若存在），本地修复失败后再回退在线安装。
- 优化大批量任务的状态汇总和界面刷新，降低任务中心、采集总览切换与拖动时的卡顿。
- 修复采集中进度广播触发所有 QML 页面重算的问题；任务控制按钮立即反馈并防止重复命令。
- 展示状态轮询改用短时缓存，停止任务的多账号线程等待改为整次最多 3 秒；启动/继续命令等待窗口延长到 240 秒，避免长采集被误报超时。
- 评论采集后的意向分析统一批量提交，即使未启用 LLM 也不再逐条处理。
- 优化评论补全、意向分析队列的收尾和退出流程，降低大量评论场景下的后台阻塞风险。
- 修复抖音大评论区短暂无新响应时提前结束：分段滚动、边接收边读取响应体，并结合 `has_more`、页面到底和待处理响应判断终止。
- 修复评论响应体过期导致的少采/漏采；单作品分页窗口延长，CDP 超时补充上下文并自动重建连接重试当前作品。
- 修复高评论量下线索扩展造成的 `database is locked`，改为小批量写入和锁冲突退避重试；监控等待账号时不再重复触发。
- 优化调度器日志、账号状态巡检和监控运行记录的数据库访问与收尾。
- 延续 2.2.5 的小红书、B 站、微博楼中楼回复定位及小红书风控降频修复。
