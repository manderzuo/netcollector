# 多平台采集工作台 V2.2.4 更新说明

## 本次修复

- 修复部分电脑更新后仍启动旧版 `src/gui.py` 的问题，启动器现在优先进入新版 QML 界面。
- 更新时自动检查 `PySide6`；缺少依赖时先补齐 `pip`，再在线安装项目依赖。
- 如果原有 `.venv` 无法修复，自动创建独立的 `.runtime` 环境，不删除原账号、任务和采集数据。
- 修复 Windows 下 `requirements-v2.txt` 中文注释造成的依赖文件编码错误。
- 监控器重启 GUI 时使用同一套运行环境检测逻辑。

## 运行说明

首次修复依赖时需要联网下载 Qt/PySide6，预计约 250 MB，实际耗时取决于网络速度。
依赖安装完成后，后续代码更新不再重复下载。

更新过程不会覆盖 `data`、`config`、`logs`、`.venv` 和 `.runtime`。
