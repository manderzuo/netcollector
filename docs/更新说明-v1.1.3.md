# 多平台采集工作台 v1.1.3 更新说明

## 本次修复

- 修复 Windows PowerShell 按系统编码读取启动脚本，导致启动器乱码、语法解析失败、自动更新检查未执行的问题。
- 启动入口改为兼容 Windows PowerShell 5 的 ASCII 脚本，中文提示运行时解码显示。
- 自动更新检查增加 `logs/update.log` 阶段日志，记录清单请求、版本比较、用户选择和异常阶段。
- 更新清单请求超时时间由 5 秒调整为 15 秒，降低首次启动时网络抖动造成的漏检。
- 保留原有 `data`、`config`、`.venv`，升级过程不覆盖用户数据和本地配置。

## 旧版本说明

如果旧版本的启动器已经因为编码错误无法解析，它无法自动修复自身，需要先使用 v1.1.3 发布包替换一次启动文件；修复后后续版本即可正常弹出更新提示。
