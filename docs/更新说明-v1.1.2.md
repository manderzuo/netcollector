# 多平台采集工作台 v1.1.2 更新说明

发布日期：2026-08-25

## 本次更新

- 修复互动中心“真实发送”确认弹窗脱离主窗口、出现在屏幕左上角的问题。
- 统一真实发送开关和单条回复确认弹窗的定位逻辑，按主窗口实时坐标居中，并限制在屏幕可见范围内。
- 后台操作日志升级为结构化审计日志，记录界面点击、滚轮、BitBrowser API、CDP 命令、页面定位、输入、发送和验证结果。
- 日志记录调用方法、参数摘要、响应状态、耗时、控件坐标、元素信息和异常堆栈；Cookie、token、密码和 API Key 自动脱敏。
- 日志每小时自动保存本地快照，程序退出时额外保存一次。
- 图片、表情包和空文本评论支持使用用户、评论时间及平台评论 ID进行定位。

## 日志位置

- 实时结构化日志：`data/logs/operation_events.jsonl`
- 小时快照：`data/logs/hourly/`
- 组件追踪日志：`data/logs/browser_reply.jsonl`、`data/logs/cdp.jsonl`、`data/logs/bitbrowser_api.jsonl`

## 安全与兼容

- 发布包不包含本机 `data/`、`exports/`、运行日志、账号绑定、浏览器登录态和测试数据库。
- 更新程序保留用户本地 `data/`、`config/` 和 `.venv/`。
- 1.1.1 用户启动时可检测到 1.1.2 更新提示。

## 本次补充修复

- 修复 Windows PowerShell 启动器编码导致的乱码、解析失败和自动更新检查未执行问题。
- 自动更新检查增加 `logs/update.log` 阶段日志，网络检查超时时间由 5 秒调整到 15 秒。
