# 多平台采集工作台 v1.1 更新说明

发布日期：2026-08-22

对比基线：v1.0.10

本次版本新增线索中心和互动中心的完整运营流程，固化抖音、小红书、B站、微博四个平台的评论定位与回复框填充流程；新增待生成、待发送、已回复、失败四阶段管理，支持完整回复模板、中文变量、原评论和失败原因展示，以及按平台匹配回复账号和批量模拟回复。

同时取消自动时效限制，补充小红书时间与地区解析，允许手动选择线索绕过自动限制进入互动中心；新增默认关闭的“真实发送”安全开关，测试时只填入回复框，不点击发送。

界面方面新增启动预加载、非当前页面移出重绘树、Canvas 线索表、分批互动卡片渲染、后台状态刷新和 Windows 原生窗口拖动/缩放冻结，解决窗口拖动、边框缩放和 TAB 切换过程中的卡顿问题。

本版本还加入完整 GUI 心跳、操作日志和性能日志，支持后台监控与自动重启。发布包不含测试数据、个人账号、浏览器登录态、窗口绑定、数据库、导出文件和运行日志。

验证结果：自动化回归测试 90 项全部通过。
