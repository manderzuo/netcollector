# 多平台采集工作台 v1.1.1 更新说明

发布日期：2026-08-22

## 本次更新

- 线索中心新增按采集任务筛选，可单独查看某个任务收集到的评论线索。
- 任务明确没有更多视频时，显示“暂无更多视频”。
- 未达到目标数量的任务提供“继续采集”，点击后重新搜索并按作品编号去重补采。
- 优化任务卡片的采集数量显示，区分视频记录数与已完成数量。
- 修复线索中心任务下拉框触发重复刷新导致的闪烁问题。
- 采集评论生成线索时补充任务与作品关联，历史数据也可反查任务归属。
- 保留抖音、小红书、微博、B站平台专属搜索排序能力。

## 安全与兼容

- 发布包不包含本机 `data/`、`exports/`、运行日志、账号绑定和浏览器登录态。
- 更新时保留用户本地 `data/`、`config/` 和 `.venv/`。
- 启动器会检查线上更新清单，旧版本启动时可收到 1.1.1 更新提示。
